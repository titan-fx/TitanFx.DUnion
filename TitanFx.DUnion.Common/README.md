# TitanFx.DUnion.Common

Some helpful discriminated unions, implemented using the [`DUnion`](https://www.nuget.org/packages/TitanFx.DUnion) source generator.

- `TitanFx.DUnion.Common.Option` mimics [Option](https://doc.rust-lang.org/std/option/) from rust
- `TitanFx.DUnion.Common.Result` mimics [Result](https://doc.rust-lang.org/std/result/) from rust
