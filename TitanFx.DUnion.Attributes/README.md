# TitanFx.DUnion.Attributes

Reusable implementations of the 4 attributes used by the [`TitanFx.DUnion`](https://www.nuget.org/packages/TitanFx.DUnion) source generator. Does nothing much on its own.

- `TitanFx.DUnion.DUnionAttribute`
- `TitanFx.DUnion.DUnionCaseAttribute`
- `TitanFx.DUnion.DUnionExcludeAttribute`
- `TitanFx.DUnion.DUnionGenericAttribute`
